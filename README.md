# rehab_zene

Feedback Portal:  

- Anonymous Feedback: Allows users to submit feedback with the option to provide their name. If the anonymous checkbox is checked, then their  name is not stored in the database.

- Feedback Types: Options to select between patient feedback or family feedback.

- Feedback Options:
      Multiple-Choice Questions: Users can answer questions to provide structured feedback.
      Text Feedback:Open text field for additional comments or suggestions.
      Rating System: Users can rate their experience on a scale of 1 to 5.


Admin Portal:

  - Basic Analytics:

     Average Rating: Displays the average rating for the centre according to the feedback received for them.
     Category Counts: Tracks and shows counts for different feedback categories (e.g., services, facilities).
     MCQ Answer Counts: Provides counts for each answer to multiple-choice questions.

  - Feedback Management:  Features to delete or manage feedback entries for effective data administration.
  

Developer Portal:  

- About Zene Ansari:  Provides information about the developer, Zene Ansari.

 - FAQs:  Includes frequently asked questions related to the system for user assistance.


Overall Features:

  - Multilingual Support: Supports both Hindi and English to cater to a wider audience.

  - Multiple Centers Support: Data from multiple rehabilitation centers is stored separately in the Firestore database, and displayed accordingly to the respective admin.
